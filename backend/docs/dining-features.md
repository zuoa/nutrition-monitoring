# 就餐行为与选餐特征

简要报告的四项特征来自实际餐次和有效菜品识别，不使用营养指标推断行为，也不计入历史补全的餐次或估算菜品。

- 就餐规律：按学校时区及配置餐次合并，每日每餐一次；至少5个不同日期的同餐次时间样本才描述中位数和中间50%时间范围。同餐次采用最早消费时间，无消费时间时采用采集时间。
- 选餐多样性：同日同餐次同菜品只计一次；前三道菜占比的分母是菜品选择次数。
- 搭配习惯：有效识别餐次中，同时识别到荤菜与素菜的比例及识别到主食的餐次数。未识别到不表示没有吃。
- 食物选择倾向：按已保存的食物组标签统计每组出现的餐次数，显示常见两组和标签覆盖的菜品选择次数。少量调味料不作为主要食物组。

菜品新增 `food_groups`、`cooking_method`、`vegetable_types` 可选字段。执行 `make migrate` 应用 `20261019_0031` 后部署应用。历史菜品保持未标注，AI 分析只在预览表单建议标签，用户保存或显式导入后用于报告；批量营养分析不自动保存标签。

菜品档案可导出 XLSX 后修改、重新导入。多选值以顿号、逗号或分号分隔；空单元格保留已有标签，`-` 清空。导出只包含启用菜品。

新报告在 `content.dining_features` 保存版本、展示文案和统计依据。旧报告在读取和导出时批量补充，不写回原报告；新报告保持生成时快照，后续菜品标签修改不改变既有报告。
